Por que o App Nativo do YouTube deixou a live esticada?

Entenda a raiz do problema ótico dos sensores e como o LiveinFé corrige isso matematicamente no Android.

App Nativo do YouTube
ALTAR ESTICADO (4:3 -> 16:9)

O que acontece:

Os sensores de câmeras de celular são nativamente 4:3. O app do YouTube em modo paisagem muitas vezes escala o buffer inteiro para 16:9 sem recortar as bordas. Resultado: pessoas e letras ficam deformadas e esticadas horizontalmente.

IRL Pro (Trabalhoso)
Erro: Chave RTMP Expirada rtmp://a.rtmp.youtube.com/live2/xxxx

O que acontece:

O IRL Pro foi feito para streamers externos e não se conecta de forma amigável com o YouTube. Toda semana a equipe precisa abrir o PC, gerar uma chave nova e digitar no celular.

LiveinFé (Solução Sob Medida)
PROPORÇÃO 16:9 REAL

Como resolvemos:

O pipeline OpenGL do aplicativo aplica uma matriz de corte central (Center Crop 16:9) antes do codificador H.264 do celular. O sinal chega ao YouTube em 1920x1080 limpo, nítido e com proporções perfeitas.

Como gerar o APK do LiveinFé para os celulares da igreja

1

Código Android Pronto

O projeto Kotlin completo com Pedro RootEncoder e YouTube API já está pronto no diretório:

/home/jonathas/.gemini/antigravity-ide/scratch/igreja-live/android
2

Habilitar a YouTube Data API v3

No Google Cloud Console:

  1. Ative a YouTube Data API v3 no projeto do canal da igreja.
  2. Em Credenciais, crie um ID do cliente OAuth (Android) com o pacote com.igrejalive.app.
3

Gerar o APK no Android Studio

Abra a pasta igreja-live/android no Android Studio e clique em Build > Build APK(s). O arquivo app-debug.apk estará pronto para ser instalado em qualquer celular Android da equipe de mídia!

4

Conexão da Mesa de Som via USB OTG

Ligue a saída auxiliar (REC OUT ou AUX) da mesa de som em uma interface USB-C (ex: Behringer UCA202, Flow 8 ou iRig) e conecte ao celular. O LiveinFé capturará o áudio a 48kHz em estéreo direto da mesa com som limpo de estúdio!
